# Miriam Makeba Tribute Page

A responsive static tribute page about South African singer and activist
Miriam Makeba, built with HTML5 and CSS3.

**Live demo:** https://anna4981.github.io/tribute-page/

## Features
- Image with caption, headline, and introduction
- Biography, Achievements, Timeline, and Legacy sections
- Semantic HTML (header, main, section, article, figure, footer)
- Centered max-width container for readable text
- Responsive layout using a media query for screens under 700px

## Approach
I planned the page structure first, wrote the semantic HTML, then styled
it with CSS using flexbox for the intro and achievements layout. I added
a media query so the layout stacks on mobile screens.

## What I learned
- Why semantic HTML improves structure and accessibility
- Using flexbox and media queries for responsive design

## Tools
HTML5, CSS3, GitHub Pages, VS Code
